# Code of Conduct

Menog OS is an open technical project. Participation should make the project safer, clearer, and more
useful.

## Expected behavior

Participants are expected to:

- treat people with respect;
- critique ideas and evidence rather than people;
- make technical disagreement specific and reproducible;
- disclose uncertainty instead of overstating results;
- respect security embargoes and private information;
- give credit for meaningful contributions;
- avoid harassment, discrimination, threats, doxxing, or deliberate disruption.

Strong disagreement is allowed. Personal attacks are not.

## Technical conduct

Because Menog OS works on agent authority, security, and observability, contributors should not:

- hide security-relevant behavior;
- intentionally bypass project review controls;
- fabricate test, benchmark, adoption, or validation claims;
- publish another person's secrets or private data;
- misrepresent generated or copied material as original work.

## Enforcement

Maintainers may edit, hide, lock, or remove content and may restrict participation when behavior
repeatedly violates this policy.

Serious security-sensitive reports should follow [SECURITY.md](SECURITY.md), not public moderation
threads.

Questions about this Code of Conduct can be raised in a normal repository issue if they are not
security-sensitive.
