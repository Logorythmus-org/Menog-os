# Support

Menog OS is experimental pre-release software and currently has no support SLA.

Use GitHub Issues for:

- reproducible bugs;
- documentation problems;
- feature proposals;
- contributor questions that can be discussed publicly.

Before opening an issue, search existing issues and include the smallest reproducible example you can.

For security-sensitive findings, **do not open a public issue**. Follow [SECURITY.md](SECURITY.md).

For contribution setup and pull-request expectations, see [CONTRIBUTING.md](CONTRIBUTING.md).
