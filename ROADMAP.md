# Menog OS Roadmap

This roadmap communicates direction, not delivery promises.

Menog OS is currently an experimental public runtime project. Work is prioritized by evidence,
security boundaries, contributor usability, and the ability to make agentic execution observable.

## Now — public project maturity

- professional contributor onboarding;
- good-first-issue and help-wanted backlog;
- protected `main` and required checks;
- deterministic test/evidence fixtures;
- private security reporting channel;
- documentation and repository-health cleanup;
- dependency-update policy and toolchain qualification.

## Next — runtime reliability and developer experience

- improve CLI discoverability and help output;
- stabilize inspect/report schemas;
- stronger runtime observability and evidence navigation;
- more reproducible recovery and failure-injection tests;
- portability qualification for supported Node/Linux environments;
- improve local federation and mesh diagnostics;
- contributor-facing architecture examples.

## Later — visible and federated runtime

- deeper GETIG inspection and explanation tooling;
- production-grade WebGPU execution qualification;
- richer agent/runtime visualization;
- broader multi-node federation experiments;
- hardened transport and key lifecycle operations;
- package/release engineering once public APIs are stable enough;
- deployment profiles for sovereign/local infrastructure.

## Explicit non-promises

The roadmap does not currently promise:

- production readiness;
- a release date;
- cloud hosting;
- autonomous administration;
- global consensus;
- a public marketplace;
- blockchain/token functionality;
- unrestricted remote execution.

Major roadmap changes should be discussed in an issue before implementation.
